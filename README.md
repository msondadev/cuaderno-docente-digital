# Cuaderno Docente Digital

Aplicación web responsive para que los docentes gestionen asistencia, calificaciones y trabajos prácticos desde el celular, la tablet o la computadora.

> Proyecto en desarrollo. Materia: Gestión de Proyectos.

## Stack

- **Backend:** Python + FastAPI
- **Base de datos:** PostgreSQL (Neon)
- **Frontend:** React + Vite (JavaScript)

## Estructura
backend/ API REST (FastAPI)
frontend/ Interfaz web (React + Vite)
docs/ Documentación y diagramas
